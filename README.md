# Germany AI Impact Dashboard

A Germany-focused AI impact dashboard built on official labor-market sources, with AI exposure and automation impact modeled as our analytical layer.
<img width="1582" height="921" alt="image" src="https://github.com/user-attachments/assets/2376debd-c0d6-44ec-85b0-f45223c273e2" />


## Live Access

- Open `index.html` locally in a browser
- If you run a local server, use the root of this repo as the web folder.
- GitHub repo: https://github.com/adityapujari98-sketch/AI-Exposure-on-Germany-Employment

## What It Shows

- Occupation employment base from official German and EU labor statistics.
- AI impact, automation exposure, and outlook as modeled analytical scores.
- A treemap visualization inspired by the Karpathy-style layout, adapted for Germany occupations.

## Sources

- Destatis occupation employment tables: https://www.destatis.de/EN/Themes/Labour/Labour-Market/Employment/Tables/occupations-gender.html
- Destatis earnings by occupation: https://www.destatis.de/EN/Themes/Labour/Earnings/Branch-Occupation/_node.html
- Eurostat Labour Force Survey: https://ec.europa.eu/eurostat/web/lfs
- Eurostat LFS information and classifications: https://ec.europa.eu/eurostat/web/lfs/information-data
- BIBB KldB classification metadata: https://metadaten.bibb.de/en/group/classification/1
- ESCO occupation classification: https://esco.ec.europa.eu/en/classification/occupation_main
- OECD AI and work: https://www.oecd.org/en/topics/sub-issues/ai-and-work.html
